Tentang Program

Program Menentukan Rute Perjalanan merupakan aplikasi sederhana untuk mencari jalur terpendek antara dua lokasi.


Program ini menggunakan Algoritma Dijkstra untuk menghitung jarak terpendek berdasarkan jaringan lokasi dan bobot jarak yang tersedia.

Algoritma Dijkstra

Dijkstra adalah algoritma yang digunakan untuk menentukan jalur terpendek dari satu titik ke titik lainnya dalam sebuah graf dengan bobot nonnegatif.
